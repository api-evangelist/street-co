# Street.co.uk

> Street.co.uk (Street Systems Limited, Manchester, England) is a UK estate agency CRM and property management platform covering residential sales, lettings, property management and client accounting. It publishes three OpenAPI 3.1 contracts — the Street Open API, the Property Feed API and the Spectre API — unauthenticated on a public Scalar developer portal. All three are JSON:API implementations authenticated with HTTP bearer tokens; production tokens are generated inside a paying agency's Street account, and non-customers must email apis@street.co.uk for a staging token.

## APIs

- [Street Open API](https://developers.street.co.uk/docs/street-open-api): The estate agency system of record — properties, sales and lettings instructions, offers, applicants, viewings, valuations, tenancies, tenants, landlords, vendors, maintenance jobs and requests, inspections, invoices, documents, e-sign documents, notes, tasks, users, branches, brands and portal listings. 74 paths, 80 operations. Base URL https://street.co.uk/open-api/v1 (staging https://demo.street.co.uk/open-api/v1).
- [Street Property Feed API](https://developers.street.co.uk/docs/street-property-feed-api): Read-only feed for powering an agency's own website — sales search, lettings search, single property, areas and features. 5 paths, all GET. Base URL https://street.co.uk/api/property-feed/v1 (demo https://demo.street.co.uk/api/property-feed/v1).
- [Spectre API](https://developers.street.co.uk/docs/spectre-api-docs): Spectre property reports and email marketing — create and retrieve property reports, retrieve report leads, contacts and segments. 6 paths, 9 operations. Base URL https://api.spectre.uk.com/v1.

## Access

- Authentication: HTTP bearer token in the Authorization header. No OAuth, no OIDC, no scopes.
- Production access requires an active Street.co.uk subscription; a third-party supplier integrates using a customer agency's token.
- Sandbox access: email apis@street.co.uk for a token on the staging environment. Spectre tokens: apis@spectre.uk.com.
- Rate limits: Street Open API 600 GET/minute and 100 write/minute; Property Feed 600/minute. No rate-limit headers are published.
